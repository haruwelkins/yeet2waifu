# Your own sounds

Put a file here and list it in `sounds.json` under the effect it replaces, for example:

```json
{ "bump": "bump.ogg", "fanfare": "fanfare.mp3" }
```

Effects: launch, impact, bump, spring, boost, warp, gel, basket, tick, beep, jingle, nobody, fanfare, wahwah,
rewind, slowDing. Anything not listed stays synthesized. Panning and pitch variation still apply. Only use sounds
you are allowed to redistribute (your own, CC0, or a license that allows it).
